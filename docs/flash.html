MitamaOS

Flash · M5Cardputer ADV · M0 test build

1Plug in & flash

Connect the Cardputer ADV to your computer by USB-C, then click Install and pick its serial port. The installer erases and writes the firmware.

This browser can't flash over USB — use desktop Chrome or Edge (see below). Serial access was blocked. Reload and allow the port prompt.
Desktop Chrome or Edge only. One-click web flashing uses the Web Serial API, which exists only in desktop Chromium browsers — not on Firefox, Safari, or any phone (Android/iOS included). On a phone, use the Launcher route below instead.

If the button errors with a missing file, the firmware hasn't been built yet — the GitHub Actions firmware workflow publishes the binaries on each push.

2No computer? Flash on-device with Launcher

If you already run Launcher on the Cardputer (it supports the ADV), you can install MitamaOS from the device itself — no PC, works from a phone-charged setup:

  1. Grab the merged image URL from the m0-test release (mitamaos-cardputer-adv-merged.bin).
  2. In Launcher, add it as a Favorite link, then install it.

3Manual flash (esptool / ESPHome-Web)

Download the merged image from the m0-test release and flash it at offset 0x0:

esptool.py --chip esp32s3 write_flash 0x0 mitamaos-cardputer-adv-merged.bin

Or drop that file into web.esphome.io. Bootloader mode if needed: hold G0, tap reset.

MitamaOS is free & open source (GPLv2). This is an early M0 test build — expect rough edges.
