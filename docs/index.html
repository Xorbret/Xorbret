MitamaOSDesign Mockups

Early design mockups for MitamaOS — a defensive, receive-only handheld OS/firmware for the M5Cardputer ADV, with a gentle companion spirit (the Mitama) that surfaces the network environment. Loosely inspired by Navi, Pokémon, and Shin Megami Tensei; styled after Cyberpunk 2077. These are concept mockups for review, not final art or shipping code.

What's decided so far

  • Name — MitamaOS
  • License — GPLv2, open source
  • Base — PaperOS core + SquachWatch detection + AdvanceOS themes
  • Hardware — Cardputer ADV (ESP32-S3, 8MB, no PSRAM)
  • Framing — Mitama · COMP · Compendium · demon races · Fiends
  • Font — Rajdhani
  • Mascot — faceless Soul form; solid-comma magatama crest
  • Personality — Clippy × GLaDOS; authored line-bank + LLM flavor
  • Temperament — sleepy after 9pm, weary after 4h; sass dial 0–3
  • Sound — sung PCM cues (portamento + vibrato)

Palette — surface over red "bones"

Receive-only / defensive by design — detects and informs, never transmits attacks. Credits: PaperOS (GPLv2, © Artem76228), SquachWatch-CYD & AdvanceOS-for-cardputer (MIT). Full design doc: ../netbuddy/outline.md.
