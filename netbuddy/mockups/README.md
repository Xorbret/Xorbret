# MitamaOS — Design Mockups

Early concept mockups for review. Self-contained HTML pages (Rajdhani loads from
Google Fonts; no other dependencies). These are **mockups for discussion**, not
final art or shipping firmware.

## View in your browser (no setup)

GitHub shows `.html` as source, so use one of these to render it:

| Icons & glyphs | [open](https://htmlpreview.github.io/?https://github.com/Xorbret/Xorbret/blob/claude/cardputer-adv-os-firmware-okqopr/netbuddy/mockups/icons.html) | esoteric app sigils + the 8 race glyphs |

Alternatively, **download the files and open them locally**, or enable **GitHub
Pages** for this branch/folder for clean URLs (then `index.html` is the entry).

## Files

- `index.html` — overview + links to the rest
- `mitama.html` — character / mascot study
- `ui.html` — screen layouts
- `icons.html` — app sigils + race glyphs
- `type-scale.html` — typography
- `sound.html` — interactive sound set

The full written design lives in [`../outline.md`](../outline.md).
