# MitamaOS — Credits & Third-Party Notices

MitamaOS is **free and open source** under the **GNU General Public License,
version 2** (see [`LICENSE`](LICENSE)). It is a defensive, **receive-first**
companion firmware for the M5Cardputer ADV. It **never transmits attacks and
never injects 802.11 frames** (no `esp_wifi_80211_tx`); monitoring is
receive-only, and the only packets it ever sends are ordinary client traffic
(ARP/ICMP/mDNS) on a network the user owns and marks trusted.

Because the OS core is GPLv2, the combined firmware is distributed under GPLv2.
That is deliberate: it keeps MitamaOS open. Anyone may use, study, modify and
redistribute it (including selling copies), but derivative firmware must also
ship its source under GPLv2 — it cannot be taken closed-source. The project
**name and logo** ("MitamaOS", the magatama mark) are held separately by the
project and are not licensed for use on derivative distributions.

## Detection signature data (`src/detect/`)

The detection engine (`signatures.h`, `detection.h`) is MitamaOS's own code.
Its rules are public facts, not anyone's code:

- **IEEE MA-L (OUI) registry** — `oui_table.h` is generated from it by
  `tools/mkoui.py`; each row is a block registered to the named company.
- **Bluetooth SIG** assigned numbers — company identifiers and 16-bit
  service UUIDs.
- Apple's Find My accessory advertisement layout, the **ASTM F3411** Remote
  ID broadcast format, and names/SSIDs the devices broadcast themselves.

## Scry (war driving) data

- **Mozilla root CA list** (via the system `ca-certificates` package),
  **MPL-2.0** — `src/net/ca_bundle.h`, generated by `tools/mkcabundle.py` in
  ESP-IDF's certificate-bundle format, so WiGLE uploads verify the server.
- **WiGLE** CSV format (WigleWifi-1.6) and upload API — wigle.net. Logs are
  uploaded only to the account the user enters, only when they press Upload.
- GPS pins from M5Stack's Cap LoRa-1262 documentation. The NMEA parser
  (`src/system/nmea.h`) is MitamaOS's own.
